# 🎬 Movie Ticket Booking System (Java)

A **Java-based console application** for managing movie ticket bookings efficiently.  
It allows users to view available movies, check show timings, and book tickets.  
The system uses **JDBC** to connect with a **MySQL database**, ensuring secure and reliable data storage.

---

## 🔧 Technologies Used
- **Java**
- **JDBC**
- **MySQL**
- **OOP Concepts**
- **Exception Handling**
- **Collections Framework**

---

## 💡 Features
- 🎫 User **login and registration**
- 🎥 Display **available movies and showtimes**
- 🪑 **Ticket booking and cancellation**
- 🗂 **Database integration** using JDBC
- ⚙️ **Validation and exception handling** for smooth user experience
